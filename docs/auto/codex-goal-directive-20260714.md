## 3. 이번에 우녕이 확정한 것 — **이게 이 지시서의 핵심이다**

이전 기획과 **다르다.** 예전 문서를 기억으로 구현하면 전부 다시 만들어야 한다.

### 3-1. 상세 패널 = **열리면 곧바로 전체화면. 목록을 완전히 덮는다.**

```
폐기: ① 살짝 480px → ② 드래그 확장 → ③ 전체  (3단계)
확정: 닫힘 | 열림(=전체화면 덮기)              (2상태)
```
- 드래그 리사이즈 **없음**. 중간 폭 **없음**.
- 사이드바 → **56px 레일**. 메뉴 이동은 계속 된다. `display:none` 금지.
- 좌상단 `⤡` = 나가기. **패널에 부착** (`position:fixed` 금지).
- **URL `?detail=<kind>/<ns>/<name>`.** 새로고침해도 열려 있다. **뒤로가기 = 닫기.**
- **`J`/`K`** — 상세를 닫지 않고 목록의 다음/이전 항목으로 이동.
- 상단에 검색 칩이 **읽기 전용 브레드크럼**으로 남는다.

→ **VP-015 §5.2 / VP-016 S6.**

### 3-2. AI 패널 = **1단계 애니메이션**

상세가 이미 전체화면이므로 "확장 → AI" 2단계가 **사라졌다.**
AI가 오른쪽에서 420px 들어오면 상세가 flex로 좁아진다. **한 번만 움직인다.**
AI 내부 콘텐츠는 **고정 420px** (여는 동안 텍스트 리플로우 금지).

→ **VP-015 §5.4 / VP-016 S7.**

### 3-3. 필터=줌은 **카메라 이동**이다 — SLG 게임 상태창 수준

> "게임 UI라고 생각해. SLG 게임에서 표현하는 다이나믹한 상태창 같아야 한다는 거지." — 우녕

**정적 리렌더 금지.**
- **예고**: 클러스터 카드 안에 **서버가 작은 블록으로 이미 보인다** (`data-morph-id`)
- **전이**: 그 블록이 **커져서 서버 카드가 된다** (FLIP, 420ms, `--ease-spring`)
- **착지**: 노드는 아래에서 위로, 70ms 스태거
- **개체감**: 파드는 scale 0.3 → 1.14 → 1.0 오버슈트, 32ms 스태거
- **되감기**: 줌아웃은 줌인의 역재생
- **골격 먼저, 살은 나중에**: `/topology` 응답을 기다리며 흰 화면·스켈레톤 깜빡임 금지

→ **VP-015 §4.6 / VP-017 §4 / VP-016 S0·S1·S4.**

### 3-4. 진행 표현 = **프로그레스바를 만들지 않는다**

세 가지로 대체:
1. **낙관적 고스트 파드** — 제출 즉시 물리 뷰에 점선 유령 파드. `applied` 이벤트에 실선이 된다.
2. **단계 레일** — 6칸 체크포인트. 완료 칸 사이 = 실제 소요시간. 미래 칸은 **안 채운다.**
3. **트레이스 워터폴** — 막대 폭 = 실제 시간. 끝난 뒤에만 그린다.

**시간 기반으로 채워지는 막대가 코드에 존재하면 FAIL.**

→ **VP-017 §7 / VP-016 S13.**


| 항목 | 기준 |
|---|---|
| 커밋 | 한 슬라이스 = **3~6 커밋** |
| 커밋 하나 | **30분 이내.** 넘으면 더 쪼갠다 |
| 슬라이스 | **반나절 이내** |
| 배포 | **슬라이스 완료 시 반드시.** 배포 안 된 슬라이스는 완료가 아니다 |

## 5. 절대 규율

### 5-1. BE-Gap 규율 (최상위)

**백엔드가 못 주는 필드·상태를 화면에 그리지 않는다.**
- 0으로 채우지 않는다 → `null`이면 **빈칸**
- disabled로 보여주지 않는다 → **렌더 자체를 안 한다**
- 6단계 중 3단계만 보고되면 **3단계만 그린다**

**화면이 얇아 보이는 건 정상이다.** 거짓말보다 낫다.

### 5-2. 단일 writer 불변식

**Opsia는 클러스터에 `kubectl apply`를 하지 않는다.** 언제나 **Git → 웹훅 → 에이전트 적용**.
"즉시 적용" 모드의 뜻은 "Git을 건너뛴다"가 아니라 **"사람의 승인을 건너뛴다"**다.

**예외 하나:** 드리프트 되돌리기(`[Git대로 되돌린다]`)는 **Git이 이미 옳으므로 Git 커밋 단계를
건너뛴다.** 재동기화만 한다. 진행 UI에서도 그 단계를 **그리지 않는다.**

### 5-3. 보안 (공개 저장소)

- **어떤 비밀 값도 커밋·문서·로그·night-log에 쓰지 않는다.** 이름과 절차만.
- IAM 신뢰 정책 `sub`는 `repo:Jungle-303-04/final:environment:dev-deploy` 에
  **StringEquals로 고정.** 와일드카드 금지 (공개 저장소 → fork PR이 role을 가로챌 수 있다).
- 클러스터 연결 `install_command`의 **토큰은 일회용 + 만료.** 콘솔·로그에 찍히면 FAIL.
- **`POSTGRES_PASSWORD=changeme`가 라이브 클러스터에 있다. 회전이 필요하다.**
  → 우녕에게 보고할 항목으로 night-log에 남긴다. (값은 쓰지 않는다)

### 5-4. DB

**개발 중에는 마이그레이션하지 않는다. 스키마가 바뀌면 DB를 날리고 다시 만든다.**
마이그레이션은 **실제 서비스 시작 후에만.**

### 5-5. 디자인

- **shadcn 단일 primitive.** 정본은 `components/ui/` 한 곳뿐.
- Radar 컴포넌트는 가져오되 **우리 shadcn 토큰으로 다시 칠한다.**
  Radar의 색·간격·모서리·duration을 **하드코딩으로 가져오면 FAIL.**
- 차트는 **recharts 단일화.** 아이콘은 **lucide 단일화.**
- **애니메이션은 `web/src/motion/` 에서만 나온다.** 컴포넌트 인라인 `@keyframes` 금지.

## 6. 전역 금지 사항 (VP-015 §11 요약)

- 검색 위치가 화면마다 다른 것
- 2층 그래프 높이가 화면마다 다른 것 (320px 고정)
- 필터가 표에만 적용되고 그래프에 안 되는 것
- **파드 크기로 위험을 표현하는 것** (크기=고정 / 채움=사용률 / 배지=비정상상태)
- **색 채널 하나에 두 의미를 싣는 것**
- 서버 위에 네임스페이스 상자를 겹쳐 그리는 것 (네임스페이스는 필터일 뿐)
- 파드를 100개 다 그리는 것 (12개 + `+N`, **문제 있는 것 우선**)
- 그래프에 "클러스터"·"노드" 같은 용어 → **서버**
- **상세를 480px 사이드 패널로 여는 것** → 전체화면 덮기
- **상세에 드래그 리사이즈·중간 폭을 만드는 것**
- **AI 패널이 왼쪽에서 열리는 것**
- **사이드바를 완전히 숨기는 것** → 56px 레일
- 로그를 우측 패널에 넣는 것 → 하단 독
- **줌 전환을 정적 리렌더로 처리하는 것**
- **노드·파드를 스태거 없이 동시에 그리는 것**
- **시간 기반 프로그레스바**
- 권한 없는 버튼을 disabled로 보여주는 것
- `prefers-reduced-motion`을 무시하는 것

## 7. 멈춰도 되는 유일한 조건

목표모드다. **승인을 기다리며 멈추지 않는다.** 아래 셋만 예외다:

1. **비밀 값을 다뤄야 하는 순간** (토큰 회전, 루트 키 삭제 등) → night-log에 절차만 적고 **우녕 승인 대기**
2. **파괴적 작업** (라이브 DB 삭제, 브랜치 강제 삭제, 인프라 파괴) → 우녕 승인 대기
3. **VP-015와 모순되는 요구가 발견됐을 때** → 임의로 결정하지 말고 night-log에
   **선택지 2~3개 + 각각의 결과**를 적고 대기. 그동안 **다른 슬라이스를 진행한다.**

그 외에는 **전부 스스로 판단하고 진행한다.**

## 9. 팀원이 보는 파일 (`docs/auto/deploy-status.md`)

**슬라이스를 닫을 때마다 갱신한다. 이걸 안 하면 슬라이스는 완료가 아니다.**

```markdown
## 지금 배포된 것

배포 SHA : a3f9c2e  (2026-07-15 03:12)
URL      : https://k8s.woonyong.org

### 완료된 슬라이스
- [x] S0  모션 기반           ← 화면 변화 없음 (토큰·훅)
- [x] S1  Clusters 목록       ← 클러스터 카드. 안에 서버 블록이 미리 보입니다
- [x] S2  클러스터 연결 위자드 ← ＋ 버튼 → 한 줄 명령 복사
- [x] S3  태그형 검색         ← 검색창에 타이핑 → 타입별 제안
- [x] S4  물리 뷰 그래프      ← 클러스터 클릭 → 서버로 줌인 (카메라 이동)
- [ ] S5  표 + 스파크라인      ← 다음

### 이번 슬라이스에서 확인할 것
1. https://k8s.woonyong.org/clusters 접속
2. 클러스터 카드 안 작은 블록이 서버 카드로 커지며 전이하는가
3. 파드가 하나씩 톡톡 튀어나오는가
4. 필터를 걸면 안 맞는 파드가 흐려지는가 (사라지지 않고)
```
