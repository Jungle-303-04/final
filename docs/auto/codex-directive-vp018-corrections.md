# VP-018 정정 지시

우녕이 배포된 `https://k8s.woonyong.org` 실물을 보고 지적했다.
**정본: `docs/spec/frontend/vp-018-shell-corrections.md`. VP-015 §5와 충돌하면 VP-018이 이긴다.**

## 0. 가장 먼저 알아야 할 것 — 내 지난 지시가 틀렸다

**VP-015 §5.2 "상세는 열리면 곧바로 전체화면. 2상태" 는 잘못된 규정이었다. 철회한다.**
우녕이 말한 "덮어야 한다"는 **확장 상태**를 뜻한 것이지 **기본 상태**가 아니었다.
그 오해 때문에 지금 `useDetailSidebarRail`이 **상세를 열 때마다 사이드바를 강제로 접는다.**
이건 우녕이 명시적으로 금지한 동작이다.

## 1. 정정 슬라이스 (순서대로. 각각 배포하고 확인)

각 슬라이스는 기존 규율 그대로: **계약 → 프론트 → 회귀 가드 → deploy-status 갱신 → push → 배포 → 눈으로 확인.**

### C1 · 상세 패널 3상태 복원 + 사이드바 독립 ★ 최우선

- 상세: **① 닫힘 / ② 살짝(480px, 목록 보임) / ③ 전체화면(콘텐츠 영역)**
- **② 가 기본값이다.** 행·파드 클릭 → 오른쪽에서 480px peek.
- **③ 은 상세 좌상단 확장 버튼(`⤢`)으로만.** 다시 누르면(`⤡`) ② 로.
- **AI를 열면 ② → ③ 자동 확장 후 AI가 오른쪽에 붙는다** (2단계, 320ms + 300ms).
- **`useDetailSidebarRail` 삭제.** 사이드바는 **자기 토글 버튼으로만** 접힌다.
  상세·전체화면·AI 무엇도 사이드바를 건드리지 않는다.
- URL: `?detail=<kind>/<ns>/<name>` 유지 + **`?detail.full=1`** 로 ③ 상태 저장.
  (폐기하려던 `full` 코덱을 되살려 정본화)
- `J`/`K` 는 ②·③ 둘 다에서 동작.
- **Issues·GitOps 상세도 같은 3상태 컴포넌트로 통일.** 지금은 구식 우측 `Sheet`다.

**회귀 가드**
- 상세를 열었는데 사이드바 폭이 변하면 **FAIL**
- 상세 기본 폭이 480px가 아니면 FAIL
- 확장 버튼 없이 전체화면이 되면 FAIL
- Issues/GitOps가 `SheetContent`로 상세를 열면 FAIL

### C2 · 사이드바 구조

- 순서: **홈 → 클러스터 → 리소스 → 인시던트 → 애플리케이션 → GitOps** (구분선) **설정**
- **`메트릭`·`카탈로그` 메뉴 제거** (기획에 없다)
- **`워크플로우` → `GitOps`** 로 이름 통일 (같은 것을 두 이름으로 부르지 않는다)
- **하단에 워크스페이스 전환 + 프로필**
  - 지금 `user-bf4f9d6a-acf5-…` UUID가 잘려 나온다. **사람이 못 읽는다.**
  - 표시: `display_name` → 없으면 `email` → 없으면 UUID 8자 + `…`. 툴팁에 전체.
  - 프로필 메뉴: 프로필 · **테마(라이트/다크/시스템)** · 설정 · 로그아웃
- **설정 화면**을 만든다 (워크스페이스 · 클러스터 · 저장소 · 멤버 · 알림 · **정책(즉시/승인)**)
- shadcn **`sidebar-*` 블록 + `NavUser` + `TeamSwitcher`** 패턴을 그대로 쓴다. 손으로 짜지 않는다.

### C3 · 1층 검색 — 칩을 입력창 **안**으로

- 지금: 칩이 입력창 **밖 왼쪽**에 떠 있고, 늘어나면 **두 줄**이 된다.
- 확정: **`🔍 [칩][칩] 필터 추가… ✕비우기` 가 하나의 border 안**에 있다.
- **절대 두 줄이 되지 않는다.** 넘치면 가로 스크롤 또는 `+N개` popover.
- **검색바 높이 고정.** 칩 개수와 무관하게 아래 레이아웃이 안 밀린다.
- 빈 입력에서 `Backspace` → 마지막 칩 삭제.
- **홈을 제외한 모든 목록 화면에 같은 위치·같은 컴포넌트로 존재한다.**
  지금은 Resources에만 있다 → **클러스터·인시던트·애플리케이션·GitOps 에 추가.**

**회귀 가드**: 칩을 5개 붙였을 때 아래 그래프의 `top` 좌표가 변하면 **FAIL**.

### C4 · 그래프 — 2배 크게, 잘리지 않게, 안 가리게

- 높이 **320px → 640px** (`--product-graph-height: 40rem` 토큰)
  - 지금 `h-96 sm:h-80` 이라 **데스크톱에서 오히려 작아진다.** 반대다. 모바일만 360px.
  - 하단 가장자리 드래그로 400~900px 조절, 값 저장
- **잘림 금지.** ELK 후 `fitView({ padding: 0.12 })`, `ResizeObserver`로 재-fit. 최소 줌 0.4.
- **오버레이가 캔버스를 덮지 않는다.**
  - 지금 툴바가 `absolute top-0` + `bg-background/80` 로 그래프를 가린다.
  - **flex column으로 바꿔 툴바가 자기 높이를 차지하고 캔버스가 남은 공간 전부를 쓴다.**
  - 꼭 떠 있어야 하는 것(힌트·줌 컨트롤·범례)만 오버레이 → **`bg-background/40` 이하, 모서리에만, `pointer-events:none`(내부 버튼만 auto)**
- **파드 12개 상한이 정의만 되고 안 쓰인다.** `MAX_VISIBLE_PODS_PER_SERVER`를 실제로 적용 + 문제 우선 정렬 + `+N개`.

### C5 · AI 패널 — 폼이 아니라 **대화**로

지금은 "한 번 묻고 끝나는 폼"이다. 대화 스레드가 없다.

- **대화 스레드**: 사용자/AI 메시지가 쌓인다. 스크롤. 자동 하단 스크롤(사용자가 위로 올렸으면 안 함 + "새 메시지 ↓")
- **스트리밍**: 토큰 단위. 커서 `▍`. 응답 중엔 전송 버튼 자리에 **[중단]**
  → **백엔드 BQ-080: `SSE /ai/chat/stream` 신설.** 지금 BQ-052는 단발이다.
- **추천 질문이 명사구다.** "선택 리소스 상태" → 이건 질문이 아니다.
  **완전한 문장**으로 바꾼다: "이 Service에 왜 파드가 안 붙어 있나요?"
  → BQ-053 응답 규격을 조인다. **`?`로 안 끝나면 FAIL.**
- **전송 버튼을 입력창 안쪽 오른쪽으로.** `Enter` 전송 / `Shift+Enter` 줄바꿈.
- **패널이 열려 있으면 FAB(✦)을 숨긴다.** 지금 입력창을 덮고 있다.
- **[＋ 새 대화] · [⟲ 이력]** 을 헤더에. `GET /ai/conversations`는 **이미 백엔드에 있다**(`ai/router.py:281`). UI가 안 쓰고 있을 뿐이다. 연결해라.
- 헤더 설명문("현재 화면의 정확한 맥락을…") **삭제.** 자리만 먹는다.
- **근거 클릭 → 그 리소스 상세가 열린다** (`?detail=`).
- evidence 없으면 답변 안 그린다 — **기존 가드 유지.**

### C6 · 테마 — 다크/라이트가 실제로 안 바뀐다

`useProductTheme`(next-themes)·`ThemeToggle`은 **존재하는데 화면이 안 바뀐다.**
→ 십중팔구 **색 토큰이 `:root`에만 있고 `.dark`에 없는 것들이 있다.**

- `styles/tokens.css` 의 **모든 semantic 색 토큰이 `:root`와 `.dark` 양쪽에 짝으로** 존재하게 한다.
- **회귀 가드**: CSS를 파싱해 `:root`의 색 토큰 중 `.dark`에 없는 것이 하나라도 있으면 **FAIL.**
- 토글을 **사이드바 하단 프로필 메뉴**에 노출 (라이트/다크/시스템).
- 기본값 **다크**.

### C7 · 클러스터 — 실제 로고 + 실시간

- provider **실제 브랜드 SVG** (`shared/brand/`, 인라인, CDN 금지). enum → 로고 매핑.
  온프렘은 lucide `server` + "우리 서버". `NOTICE`에 상표 출처 표기.
- **실시간이 없다.** 지금 한 번 불러오고 끝이다.
  - 클러스터 카드·개수·인시던트: **폴링 10초**
  - 그래프의 파드 상태·사용률: **폴링 5초**
  - `refetchIntervalInBackground: false` (탭이 뒤에 있으면 멈춘다)
  - **"N초 전 갱신"** 을 1층 오른쪽에 표시. 멈추면 사용자가 안다.
