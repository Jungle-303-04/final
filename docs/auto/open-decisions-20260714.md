# 미확정 결정 6건

우녕이 자러 가기 전에 시안(visualize)으로 제시했다. 아침에 바뀔 수 있다.
**바뀌기를 기다리며 멈추지 않는다.** 아래 기본값으로 구현하되,
**바꾸기 쉽게 한 곳에 격리**해 둔다 (아래 "격리 지점").

| # | 결정 | **기본값** | 대안 | 격리 지점 |
|---|---|---|---|---|
| D1 | 시간 스크럽 UI | **기준 원본 히스토그램 + 밴드** (QUERY/WINDOW 분리) | 단순 슬라이더 | `timeline/` 모듈 전체. 다른 화면은 `<TimelineStrip/>` 하나만 부른다 |
| D2 | 파드 축약 | **12개 + `+N개`** (문제 우선 정렬) | 밀도 히트맵 / 토글 | `topology/podTruncation.ts` — 상한값과 정렬 함수만 |
| D3 | 클러스터 2~4개 선택 | **나란히 축소** (5개↑는 격자) | 격자 유지 | `topology/zoomLevel.ts` — 임계값 상수 |
| D4 | 첫 화면 | **Clusters** | Home | 라우터 `index` 리다이렉트 한 줄 |
| D5 | Resources 2층 기본 뷰 | **물리 뷰** | 관계 뷰 | URL 기본값 `?view=physical` 한 곳 |
| D6 | 기본 테마 | **다크** | 라이트 / OS 따름 | `theme.css` 루트 클래스 |

**격리가 규율이다.** D1~D6이 바뀌었을 때 **각각 한 파일만 고쳐서 끝나야 한다.**
이 결정들이 여러 컴포넌트에 스며들면, 아침에 우녕이 바꿔달라고 했을 때 못 바꾼다.

## 이미 확정된 것 (바뀌지 않는다)

- 상세 패널 = **열리면 곧바로 전체화면. 목록을 완전히 덮는다.** 2상태. (VP-015 §5.2)
- AI 패널 = **오른쪽에서. 1단계 애니메이션.** (VP-015 §5.4)
- 필터=줌 = **카메라 이동. SLG 게임 상태창 수준.** (VP-015 §4.6, VP-017 §4)
- 진행 표현 = **고스트 파드 + 단계 레일 + 트레이스 워터폴.** 프로그레스바 금지. (VP-017 §7)
- 파드 인코딩 = **크기 고정 / 채움=사용률 / 배지=비정상상태.** 3채널 독립. (VP-015 §4.2)
