# 절대 규율

BE-Gap 규율 (최상위)
  백엔드가 못 주는 필드·상태를 화면에 그리지 않는다.
  0으로 채우지 않는다 (null이면 빈칸). disabled로 보여주지 않는다 (렌더 자체를 안 한다).
  6단계 중 3단계만 보고되면 3단계만 그린다.
  **화면이 얇아 보이는 건 정상이다. 거짓말보다 낫다.**

단일 writer 불변식
  Opsia는 클러스터에 kubectl apply 하지 않는다. 언제나 Git → 웹훅 → 에이전트 적용.
  "즉시 적용"의 뜻은 "Git을 건너뛴다"가 아니라 **"사람의 승인을 건너뛴다"**다.
  예외 하나: 드리프트 되돌리기는 Git이 이미 옳으므로 Git 커밋 단계를 건너뛴다.
  그리고 진행 UI에서도 **그 단계를 그리지 않는다** (그리면 거짓말이다).

디자인
  shadcn 단일 primitive. 정본은 components/ui/ 한 곳뿐.
  Radar 컴포넌트는 가져오되 **우리 shadcn 토큰으로 다시 칠한다.**
  Radar의 색·간격·모서리·duration을 하드코딩으로 가져오면 FAIL.
  차트 = recharts 단일화. 아이콘 = lucide 단일화.

  prefers-reduced-motion 처리 없으면 FAIL.
