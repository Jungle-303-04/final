# VP-012 — Resources 4층 구조

## 0. 확정 사항 (우녕 기획, 2026-07-14)

**표현 모드 탭 전환을 폐기한다.** 그래프와 표는 **한 화면에 위아래로 동시에** 표시한다.
사이드바에 Topology·Timeline 메뉴를 두지 않으며, 상세 진입도 탭이 아니라 우측 패널로 연다.

## 1. 각 층의 계약

### 1.1 필터 (1층)
VP-010 문서가 정본. 변경 없음.

### 1.2 시간 스크럽 바 (2층) — 확정 (2026-07-14, 프로토타입 검증 완료)

**형태: 그래프 영역 하단의 오버레이 바. 레이아웃을 밀지 않는다.**
유튜브 플레이어와 동일한 패턴 — 평소엔 완전히 숨어 있다가 그래프에 마우스를 올리면
아래에서 떠오른다. `position:absolute; bottom:0`으로 그래프 영역 위에 겹치며,
문서 흐름에 공간을 차지하지 않는다. **자리를 잡아두는 슬롯 방식·탭·항상표시 모두 폐기.**

**구성 요소는 단 두 개다:**
```
[▶]  [────────●───────────]
 ↑         ↑         ↑
재생    슬라이더   인시던트 마커(빨간 눈금)
```
[현재로] 버튼, 시각 라벨, 배속 버튼, 시간 프리셋을 **바 안에 두지 않는다.**

**상태와 전환:**
| 상태 | 조건 | 표시 |
|---|---|---|
| 숨김 | 라이브 + hover 아님 + 재생 아님 | 바 없음 (`translateY(6px)`, opacity 0) |
| 표시 | 그래프 영역 hover | 바가 떠오름 (200ms ease) |
| 과거 | 슬라이더가 끝이 아님 | 바 계속 표시(hover 무관) + 상단에 "과거 · 11:47" 배지 |
| 재생 | [▶] 클릭 | 바 계속 표시 + 아이콘이 ⏸로 |

- **라이브 해제**: 슬라이더를 만지는 행위 자체가 해제다. 별도 정지 버튼 없음.
- **라이브 복귀**: 슬라이더를 오른쪽 끝까지 밀거나, 재생이 끝에 도달하면 자동 복귀.
  별도 [현재로] 버튼 없음.
- **[▶] 동작**: 라이브 상태에서 누르면 자동으로 과거 지점으로 이동 후 재생 시작
  (사용자가 "되감기 → 재생" 2단계를 밟지 않게 한다). 끝 도달 시 자동 정지 + 라이브 복귀.
- **드래그 중 툴팁**: 손잡이 위에 시각(`11:47`)을 툴팁으로. 손을 떼면 사라진다.
  라이브 위치에서는 `지금`으로 표기.
- **인시던트 마커**: 슬라이더 트랙 위의 빨간 세로 눈금.
  - hover → "장애 · 11:47" 툴팁 (danger 색상)
  - **클릭 → 그 시각 직전으로 점프**. 이후 [▶]로 장애 순간을 재생할 수 있다.
    이것이 데모의 핵심 동선이다: 마커 클릭 → 재생 → 파드가 죽는 장면.
- **데이터 없는 구간**: 트랙에서 회색으로 표시하고 그 구간으로 스크럽하면
  "이 구간의 스냅샷 없음"을 그래프 영역에 표시한다. **보간으로 없는 상태를 만들지 않는다.**
- **접근성**: 슬라이더는 네이티브 `input[type=range]`(키보드 조작 가능, `aria-label="시간"`).
  마커는 `button`(키보드 포커스 가능, `aria-label="장애 시각으로 이동"`).
  `prefers-reduced-motion`이면 transform 없이 opacity만, 재생 애니메이션은 즉시 전환.

**시간 범위 선택**: 바 밖에서 처리한다(필터 바 우측 또는 그래프 우상단의 작은 셀렉트).
프리셋 15m / 1h / 6h / 24h. URL `t.range`, 스크럽 위치는 `t.at`.

**인시던트 상세와의 관계**: 같은 컴포넌트를 재사용하되 **시작 시각만 다르다.**
- Resources에서 열면 → 초기값 = 라이브(끝)
- 인시던트 상세(조사 탭)에서 열면 → 초기값 = 장애 발생 시각, 마커에 고정
동일 조작법, 동일 컴포넌트. 중복 구현 금지.

### 1.3 그래프 (3층) — 물리 뷰 기반, 상세 기획 대기

**확정된 것:**
- 레이아웃은 **물리 뷰**(서버 아이콘 위에 파드가 놓인 형태)를 기본으로 한다.
  쿠버네티스 용어("클러스터/노드")가 아니라 **서버 그림**으로 직관성을 확보한다.
- 시간 슬라이더에 종속된다(그 시각의 배치를 그린다).
- 단일 클러스터일 때만 렌더한다. 클러스터 칩이 2개 이상이면
  "그래프는 클러스터 하나를 선택해야 합니다" 안내.

**대기 중인 것 (별도 기획):**
- 노드/파드의 시각적 표현(크기·색·아이콘 규칙)
- 파드가 많을 때의 축약 규칙(예: "+42개")
- 관계(서비스·볼륨) 표현 여부와 방식
- 상호작용(줌·팬·선택)

**이번 구현 범위**: 그래프 **영역만 확보**한다(레이아웃 슬롯 + 로딩/빈 상태).
계약이 도착하고 상세 기획이 확정되면 그 안을 채운다. **추측으로 그리지 않는다.**

### 1.4 표 + 스파크라인 (4층)

- 표는 필터 결과 목록. 정렬·페이지네이션은 기존 규칙.
- **추세 컬럼(스파크라인)**: 각 행에 작은 시계열 그래프. 슬라이더의 시간 범위에 종속.
  - 지표: CPU 사용률(기본). 향후 메모리 전환 가능.
  - 데이터 없으면 스파크라인 자리를 비워둔다(0으로 그리지 않는다).
- **행 또는 스파크라인 클릭 → 우측 패널**(§1.5). 새 화면으로 이동하지 않는다.

### 1.5 우측 패널 (상세)

- 큰 차트(CPU/메모리), 해당 시각의 로그, 관련 인시던트 링크.
- **필터는 적용하지 않는다**(VP-010 §2.5: 상세는 하나의 진실).
- 슬라이더 시각에 종속된다 — 과거 시점이면 그 시점의 로그·메트릭.
- 인시던트가 있으면 [인시던트 보기]로 인시던트 상세(판단/조사/복구/여정 탭)로 이동.

## 3. 구현 순서

1. **레이아웃 4층 골격** — 필터(기존) + 슬라이더 자리 + 그래프 빈 슬롯 + 표. 계약 없이 가능.
2. **표 + 스파크라인** — GAP-012 착륙 후.
3. **시간 슬라이더 (정지 상태)** — GAP-011 착륙 후. 슬라이더 이동 시 표·스파크라인 갱신.
4. **우측 패널** — GAP-012·014 착륙 후.
5. **재생(애니메이션)** — 3 완료 후.
6. **물리 뷰 그래프** — GAP-013 + **별도 기획 확정** 후. 그 전까지 슬롯은 빈 상태 유지.

## 4. 금지 사항

- 그래프를 추측으로 그리지 않는다(기획·계약 대기 중 = 빈 슬롯).
- 스냅샷 없는 구간을 보간해 채우지 않는다.
- 스파크라인·차트를 데이터 없이 0으로 그리지 않는다.
- 표현 모드 탭·Topology 메뉴·Timeline 메뉴를 만들지 않는다(4층 동시 표시가 확정안).
- 상세를 새 화면으로 열지 않는다(우측 패널).
