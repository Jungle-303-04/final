# 데모 대조 제품 결함 원장

기준 화면은 읽기 전용 `demo/motion-animations`의 `demo-freeze-v3`이며, 제품 코드를 복사하지 않고 `OPSIA-SURFACE-SPEC.md`의 요소 계약과 제품 토큰·i18n·가드로 재구현한다. 항목은 동일 후보 SHA의 자동 테스트, 라이브 화면, 숫자 교차 대조, 클릭 경로가 모두 일치할 때만 제거한다.

## 미해소

### D-1 · 배포 GitOps 정보·흐름 소실 · 블로커

- 관측: 라이브 `/deploy`의 저장소·동기화 탭에서 구 `/gitops`가 제공하던 저장소 목록, 연결 흐름, 애플리케이션별 동기화 상태가 보이지 않고 플랜 선택 빈 상태만 노출된다.
- 원칙: D19 병합은 정보와 동작의 소유권을 `/deploy`로 옮기는 것이며 삭제가 아니다.
- 완료 조건: 저장소 목록·연결 진입·연결 진행/완료·동기화 상태/health/revision/coverage가 `/deploy` 탭 안에서 실제 API로 표시되고, demo 대조·죽은 컨트롤 0·동일 SHA 라이브 증거를 남긴다.
- 상태: 로컬의 overview 바인딩과 authoritative reflection은 구현됐으나 전체 구 GitOps 정보 요소 복원과 라이브 검증 전이므로 미해소다.

### D-2 · 애플리케이션 빈 상태의 죽은 순환 참조 · 블로커

- 관측: 애플리케이션 탭의 `GitOps에서 애플리케이션 연결` 행동이 연결 흐름이 없는 화면으로 이동한다.
- 완료 조건: 행동이 `/deploy` 저장소·동기화 탭의 실제 연결 흐름을 열고, 연결 완료 뒤 애플리케이션 목록·동기화 상태에 한 사건으로 반영된다.
- 상태: 미해소. D-1과 같은 배포 서피스 배치에서 검증한다.

### D-3 · 서피스별 라이트/다크 혼재 · 블로커

- 관측: 라이브 서피스 사이에서 배경·카드·텍스트·상태색의 라이트/다크 문법이 섞인다.
- 기준: demo의 라이트 화면과 제품 단일 테마 토큰을 사용하며 서피스 로컬 색상·임의 그림자·리터럴 duration을 허용하지 않는다.
- 완료 조건: 홈부터 설정까지 8개 canonical 서피스를 같은 라이트 토큰으로 촬영하고 `check:design`, reduced-motion, 키보드 포커스와 3개 viewport를 통과한다.
- 상태: 미해소. 홈 → 배포 → 리소스 → 인시던트 → 타임라인 → 점검 → 비용 → 설정 순으로 소거한다.

### D-4 · 홈 데이터 미연결·3층 보드 부재 · 블로커

- 관측: 라이브 홈 클러스터 카드의 지표가 모두 `—`이고 W2~W8 3층 위젯 보드가 보이지 않는다.
- 완료 조건: 선택 없음에서도 접근 가능한 전체 플릿을 bounded fan-out으로 집계하고, 헤더·클러스터 카드·W2~W8이 실제 API 수치 또는 정직한 부분 상태를 표시한다. 임계 칩 수는 `/resources?health=critical` 착지 행수와 같아야 한다.
- 상태: 이 후보에서 홈 플릿 보드·namespace 경계·exact critical/scope/다중 앱 P0를 구현했고 표적 28/28을 통과했다. 후보 배포·demo 대조 전이므로 미해소다.

## 배포 단위

1. 첫 배치: 홈 이식·데이터 연결만 검증해 단일 후보로 배포한다.
2. 다음 UI 배치: 배포 D-1·D-2와 GitOps 아카이브 기능을 현행 D19 구조에 이식한다.
3. 이후: 리소스부터 설정까지 1~2개 서피스씩 demo 대조 증거를 남긴다.
