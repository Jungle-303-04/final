# RCA 동적 UI 데모

Buildbleu 계열의 깔끔한 워크플로우 캔버스 감각을 기준으로, 우리 RCA/운영 콘솔에 필요한 화면을 직접 실행해 볼 수 있게 만든 독립형 React 데모입니다.

## 실행

```bash
npm install
npm run dev
```

## 확인할 것

- 액션 플로우를 실행해 노드와 연결선 상태 변화를 확인합니다.
- 증거 노드, 승인 게이트, 캔버스 차트 노드를 동적으로 추가합니다.
- 화면 카탈로그에서 Plural 계열 콘솔 화면군을 우리 톤으로 재구성한 템플릿을 확인합니다.
- 그래프 랩에서 동일한 실시간 더미 프레임이 여러 차트로 동시에 반영되는지 확인합니다.
- 라이트/다크 모드와 실시간 토글을 오가며 대비와 움직임을 확인합니다.

이 데모는 일부러 독립 폴더로 분리했습니다. 모든 UI 소스는 `src/` 아래에서 바로 확인할 수 있습니다.

## 구조

- `src/data/*`: 화면 문구, 노드 매니페스트, 화면 카탈로그, 그래프 모듈, 더미 실시간 프레임, 이벤트 템플릿.
- `src/components/*`: 재사용 렌더러. 데모 데이터는 컴포넌트에 넣지 않습니다.
- `src/types.ts`: 나중에 API 응답으로 교체할 공유 계약.
- `src/App.tsx`: 상태 조합, 인터랙션, 실시간 갱신 루프.
