# shadcn/ui Official Lab

공식 shadcn/ui 소스를 고정 커밋으로 내재화한 프론트엔드 레퍼런스와, 백엔드 연동 제품 화면을 분리해 보관합니다. 기존 자체 제작 500개 예제는 제거했습니다.

현재 upstream은 `shadcn-ui/ui@21e4ceb94418096e21a7f1990027741a8f9b085d`입니다.

## 포함 범위

- Components 문서 64페이지에서 참조하는 실제 Preview 445개
- Area Chart 공식 예제 10개
- 공개 Blocks 27개
- Components 랜딩용 공식 overview 64개
- 각 항목의 upstream 원본 소스와 MIT 라이선스

문서 기준 고유 Preview 482개(445 + 10 + 27)는 production build에서 전수 렌더링합니다. 공식 사이트가 사용하는 `base-nova`, `base-rhea`, `radix-nova`, `new-york-v4` 소스를 namespace별로 분리해 서로 덮어쓰지 않습니다.

## 실행

```bash
cd references/ui-layer-lab
npm install
npm run dev -- --port 5194
```

- `/` 또는 `/components` — 공식 Components overview
- `/components/examples` — 공식 문서 Preview 445개
- `/charts/area` — Area Chart 10개
- `/blocks` — 공개 Blocks 27개
- `/installation` — 실제 설치 설정과 소스
- `/product` — 백엔드 계약을 사용하는 Fleet Control Room

레퍼런스 경로는 백엔드 없이 동작하며 `/api`를 호출하지 않습니다. 각 Preview는 iframe으로 격리되고, `Source` 탭은 변형하지 않은 upstream 파일을 지연 로딩합니다.

## 검증

```bash
npm run check
npm run visual:shadcn
npm run audit:shadcn
npm run visual-product
```

- `check:shadcn`은 항목 수, 원본 파일 SHA-256, 라이선스와 기존 예제 제거 여부를 검사합니다.
- `visual:shadcn`은 Component·소스 탭·Chart·Block·라이트/다크·390px 화면과 `/api` 요청 0건을 검사합니다.
- `audit:shadcn`은 build 후 문서 기준 Preview 482개를 모두 브라우저에서 렌더링합니다.
- `visual-product`의 API 응답은 테스트 파일에서만 모킹하며 제품 런타임에는 fixture가 없습니다.

## 구조

```text
src/
  App.tsx                    # backend-independent lab entry
  shadcn-lab/                # catalog shell, iframe preview, source viewer, adapters
  components/ui/             # official Base Nova install generated by shadcn CLI
  product/                   # backend-backed production frontend
vendor/shadcn/
  inventory.json             # source URLs, commit, item inventory, file hashes
  LICENSE.md                 # upstream MIT license
  upstream/                  # byte-preserved official source snapshot
scripts/
  sync-shadcn.mjs
  check-shadcn.mjs
  shadcn-visual-gate.mjs
  shadcn-exhaustive-audit.mjs
```

`vendor/shadcn/upstream`은 수동으로 수정하지 않습니다. 공식 소스를 갱신할 때만 해당 커밋의 checkout을 넘겨 동기화합니다.

```bash
npm run sync:shadcn -- /absolute/path/to/shadcn-ui
npm run check:shadcn
```

커밋을 의도적으로 올릴 때만 `SHADCN_UPSTREAM_COMMIT=<full-sha>`를 명시하고 새 스냅샷을 검증합니다.
